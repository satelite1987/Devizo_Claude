===============================================
DACA CEVA NU MERGE
===============================================

PROBLEMA 1: "Eroare conexiune baza de date"
-------------------------------------------
Cauze:
- Baza de date nu exista (devizo_db)
- User-ul nu exista (devizo_user)
- Parola gresita (Satelite1987!)
- User-ul nu are permisiuni pe baza de date

Solutie:
1. Verificati in cPanel > MySQL Databases
2. Verificati ca user-ul e adaugat la database
3. Verificati cu ALL PRIVILEGES


PROBLEMA 2: "Table 'devizo_db.utilizatori' doesn't exist"
----------------------------------------------------------
Cauza:
- database.sql nu a fost importat corect

Solutie:
1. phpMyAdmin > devizo_db > Tab "Structure"
2. Daca nu vedeti tabele, reimportati database.sql
3. Asigurati-va ca baza e selectata (stanga) inainte de import


PROBLEMA 3: "Cannot upload logo" / "Permission denied"
-------------------------------------------------------
Cauza:
- Folder-ul assets/uploads nu are permisiuni 775

Solutie:
1. File Manager > devizo/assets/uploads/
2. Change Permissions > 775
3. Bifati "Recurse into subdirectories"


PROBLEMA 4: Pagina alba / Eroare 500
-------------------------------------
Cauze:
- Versiune PHP prea veche
- Extensii PHP lipsa
- Eroare de sintaxa

Solutie:
1. Verificati PHP Version (MultiPHP Manager)
2. Trebuie minim PHP 7.4, recomandat 8.1+
3. Activati DEBUG_MODE = 1 temporar pentru a vedea eroarea
4. Verificati logs/app.log


PROBLEMA 5: CSS nu se incarca / Link-uri rupte
-----------------------------------------------
Cauza:
- SITE_URL incorect in config (DAR E DEJA CONFIGURAT CORECT!)

Verificare:
config/database.php trebuie sa contina:
define('SITE_URL', 'https://www.devizo.ro');


PROBLEMA 6: "Access Denied" la phpMyAdmin
------------------------------------------
Cauza:
- Credentiale MySQL gresite

Solutie:
1. Incercati din nou cu:
   User: devizo_user
   Password: Satelite1987!

2. Daca nu merge, resetati parola in cPanel > MySQL Databases
